# 基于 FPGA 的激光诱偏系统 — RTL 与验证工程

面向激光半主动制导威胁的探测、解调与诱偏干扰一体化实现。

系统的工作方式：接收端捕获照射到平台上的激光编码脉冲，测出脉冲间隔并解调出威胁编号；发射端按该编号从本地波形库取出对应的诱骗波形，回射到光域，使来袭导引头的跟踪点偏离真实目标。**不追求对弹体的物理毁伤，而是干扰其导引链路。**

## labs/ — 验证工程

接收链路的解调算法与支撑模块，全部配有**自带激励与判据**的测试台，仿真结束直接给出通过与否，无需人工比对波形。

一次跑完 9 组：

```powershell
cd labs
powershell -ExecutionPolicy Bypass -File .\run_all.ps1
```

当前结果：**通过 9 / 未通过 0**

| 测试台 | 验证内容 |
| --- | --- |
| `tb_counter_ce` | 计数器使能与间隔/宽度计时 |
| `tb_dds` | 相位累加器频率换算 |
| `tb_debounce` | 按键消抖 |
| `tb_fsm_seq3` | 三段式状态机符号序列 |
| `tb_edge_detect` | 边沿检测与同步 |
| `tb_sync_fifo` | 跨时钟域 FIFO |
| `tb_gold_code` | Gold 码优选对判定（互相关上界） |
| `tb_uart_loopback` | 串口回环收发 |
| `tb_dpim` | DPIM 判决门限对比（整除 vs 居中） |

其中 `tb_dpim` 的对比实验支撑了一个关键设计决策：发送端时隙负向漂移 10% 时，整除判决出现 12 个符号错误（含 4 个越界间隔），改用居中判决后错误数为零；正向漂移 10% 时两种判决均未出错 —— 说明整除判决的门限不对称，缺陷只出现在负方向。这一现象在无漂移的单点测试中无法察觉。

依赖：[Icarus Verilog](https://steveicarus.github.io/iverilog/)（`iverilog` + `vvp`）。

## laser_dds_ACM9767/ — 发射端

32 位相位累加器驱动的 DDS 波形回放引擎：频率控制字只改变回放速率，波形数据不动；块 RAM 存放按 8192 点分段的诱骗波形库，段基址由编号左移得到，段内偏移取低位即天然回绕。

- 回放速率、起始相位、输出开关三项均由 VIO 在线切换，无需重新综合
- 综合实现时序：WNS +3.567 ns，TNS 0

用 Vivado 2020.2 打开 `laser_dds_ACM9767.xpr` 即可。

> 仓库只包含源码与 IP 描述文件（`.xci`），不含 `runs/`、`cache/` 等构建产物，构建时间约 5~10 分钟。
